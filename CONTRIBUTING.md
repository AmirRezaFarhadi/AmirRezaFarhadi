# Contributing

Thanks for considering a contribution. The most helpful contributions start with a reproducible problem: the command you ran, a minimal safe input, the expected result, and the actual result. Please do not include customer exports, API keys, or personal data in an issue or pull request.

For a code contribution, keep the change focused, add or update an automated test when behaviour changes, and update the README if the first-use experience changes. These repositories prefer transparent, dependency-light solutions over broad platform abstractions.
